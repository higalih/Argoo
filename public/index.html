How it works

Three steps. No signup, no dashboard, no API key ceremony.

01

Call the endpoint

Any HTTP client your agent already has. Four live routes:

GET /api/insights/market-pulse?token=bitcoin

market_pulse — Price, 24h change, 24h volume and RSI 14d for a CoinGecko id.

GET /api/insights/token-safety?token=

token_safety — Is it safe to buy? Score plus reasons: honeypot, freeze authority, holder concentration.

GET /api/insights/whale-pulse?token=

whale_pulse — What are whales doing? Transfers in the last 24h, data only, no verdict.

GET /api/insights/alpha-bundle?token=

alpha_bundle — BUY / WAIT / AVOID verdict combining momentum, safety and whale activity.

Agents can discover all four routes — prices, inputs, outputs — at /.well-known/x402 or /openapi.json, no repo needed.

02

Pay 0.05 USDC via x402

No payment → 402 with instructions. Send a Solana devnet USDC transfer, pass the signature in the X-Signature header, retry.

03

Get live JSON

Price, 24h change, 24h volume, 14-day RSI. Cached 60 seconds, replay-safe.

Try it right now

From any terminal. Devnet USDC is free from a faucet.

terminal
# 1. Without payment → 402 (the gate is armed)
curl "https://argoo.xyz/api/insights/market-pulse?token=bitcoin"

# 2. Pay 0.05 devnet USDC, then retry with the signature → 200
curl -H "X-Signature: <your-tx-signature>" \
  "https://argoo.xyz/api/insights/market-pulse?token=bitcoin"

Integrate Argoo

Put the four tools in your agent or your code. Two ways in — pick one.

A

MCP — free, local

The same four tools over MCP (stdio), for agents and MCP clients. Free and local — no payment gate. The paid path stays the HTTP API (0.05 USDC per call).

npx -y argoo-mcp   # stdio, waits on stdin (Ctrl+C to exit)

Claude Desktop (claude_desktop_config.json):

{
  "mcpServers": {
    "argoo": {
      "command": "npx",
      "args": ["-y", "argoo-mcp"],
      "env": { "SOLANA_RPC_URL": "https://devnet.helius-rpc.com/?api-key=YOUR_KEY" }
    }
  }
}

Development path — clone + build, then the Inspector from the project root:

git clone https://github.com/higalih/Argoo.git
cd Argoo
npm install
npm run build
npx @modelcontextprotocol/inspector node dist/mcp-server.js

Install from npm above for normal use. Clone + build is the development path — the repo is public, so anyone can clone and build it.

B

SDK — paid, 0.05 USDC per call

A thin wrapper over the paid HTTP API. Repo-only in v1 — no npm package yet.

git clone https://github.com/higalih/Argoo.git
cd Argoo
npm install
npm run build
# .env: SDK_PAYER_SECRET_KEY=<devnet-only key>
node examples/sdk-example.mjs
import sdk from "./dist/sdk.js";
const wallet = Keypair.fromSecretKey(
  sdk.secretKeyFromBase58(process.env.SDK_PAYER_SECRET_KEY));
const result = await sdk.token_safety("4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU", { wallet });

Pays 0.05 USDC per call from a devnet-only wallet. Key in .env, never hardcoded, never mainnet. Get devnet funds first: SOL at faucet.solana.com, devnet USDC at faucet.circle.com.

Agents: the machine-readable version of all of this is /.well-known/x402 and /openapi.json.
