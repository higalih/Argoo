Agent Pay Gate

Pay-per-call API for AI agents. Pay a small USDC fee on Solana per call, the server verifies the payment on-chain, then returns the data.

Status: checking…

Endpoint

GET /api/insights/market-pulse?token=bitcoin

Price, 24h change, 24h volume, 14-day RSI. Send a Solana USDC transaction signature in the X-Signature header. Without a valid payment the server returns 402.

Example

curl -H "X-Signature: YOUR_TX_SIGNATURE" \
  "http://localhost:8080/api/insights/market-pulse?token=bitcoin"

Devnet by default — no real money.
